\# Architecture



\## Status



DESIGN IN PROGRESS



\## Rule



This document is the canonical technical architecture.



AI agents must NOT invent missing architecture.



Before implementation, the team will define:



\- system components

\- data flow

\- baseline representation

\- audio preprocessing

\- transcription

\- forced alignment

\- feature representation

\- normalization

\- contrastive comparison

\- temporal grounding

\- severity

\- scoring

\- explanation layer

\- API contracts

\- frontend/backend boundaries

\- dataset schema



When an architecture decision is finalized, it must be documented

here and, where appropriate, recorded in DECISIONS.md.



Until then, agents should not make major architectural assumptions.# Architecture
